A small fix for opening videos from Explorer.

## Changes

- **Videos opened from Explorer go straight to the player.** When Dropreel was started by opening a video (with *Open with*, or as your default player), the library showed for a moment before the video began. It now shows the player's loading screen until the video plays.

## Download

| File | What it is |
|---|---|
| **`Dropreel-0.4.0.1-setup.exe`** | Installer (recommended). It installs over earlier versions, and your library and settings stay where they are. Install it to have Dropreel appear in Default apps. |
| `Dropreel-0.4.0.1-win64.zip` | Portable version: unzip anywhere and run `Dropreel.exe`. It doesn't register itself with Windows, so it won't appear in Default apps. |
| `SHA256SUMS.txt` | Checksums for both downloads. |

Requires 64-bit Windows 10 or 11. The files aren't code-signed, so SmartScreen may warn: choose **More info → Run anyway**.
