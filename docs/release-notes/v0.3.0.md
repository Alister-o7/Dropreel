DropReel now handles TV shows as well as movies. This release also brings sharper posters, a header that no longer overlaps itself, and a fix for duplicate entries after re-encoding.

## What's new

- **Shows.** Episode files become one show, with seasons and episodes. DropReel recognises these names:
  - `Show.Name.S01E02.mkv`
  - `Show Name - 1x02 - Title.mkv`
  - plain `S01E02.mkv` inside a `Show Name/Season 1` folder

  Episodes already in your library are sorted into their shows the first time you start 0.3.0.
- **One card per show.** Click the card to see the episodes, with a tab for each season. The play button in the middle of the poster plays the episode you're on, or the next one. New **Movies** and **Shows** shelves split the library. Search, sort, tags and the other shelves work on whole shows.
- **Up next.** At the end of an episode, an *Up next* card plays the next one after a few seconds, and you stay in fullscreen. Press **N** or the ⏭ button to skip ahead at any time. The player shows the show's name with the episode beside it.
- **Show artwork from TMDb.** With a TMDb key, new shows get their poster, plot and episode titles. You can also look a show up again from its panel.
- **Sharper posters.** TMDb posters are downloaded at 780 pixels wide, up from 500. Posters from earlier versions are fetched again in the background, and large posters stay crisp when shown small.

## Fixes

- **No duplicate after a re-encode.** After a re-encode, the original file no longer comes back as a second, larger entry when a watched folder is scanned. Deleting or recycling the original also removes any leftover entry that still points to it.
- **Header no longer overlaps.** When the window is narrow or the details panel is open, the page title, search box, sort menu and buttons no longer draw over each other. They move onto extra lines instead.

**Note:** 0.3.0 updates the library database. Once 0.3.0 has run, earlier versions can't open your library.
