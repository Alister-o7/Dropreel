A fix for the moment one episode hands over to the next.

## Fixes

- **No frozen picture when the next episode starts.** After *Play now*, or when the *Up next* countdown ran out, the last frame of the previous episode stayed on screen for a second or two while the next one opened. The screen now goes black with *Loading…* until the new episode's picture is ready.
- **Quicker switch between episodes.** The next episode's file now replaces the current one directly instead of stopping the player first, so there's less to restart and it opens faster.
