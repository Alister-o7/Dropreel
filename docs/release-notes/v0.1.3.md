A fix release for DropReel 0.1.2, from a new automated test suite that drives the library, the player and the whole app.

## Fixes

- **Junk files are no longer added as movies.** Empty, unreadable or audio-only files with a video extension now show up under *Failed* in the import report instead of becoming a broken entry. For watched folders, each one is reported once per session.
- **Notifications no longer cover buttons.** They now appear at the bottom centre (above the player bar while a movie plays) instead of over the details panel's *Remove from library* button and the player's Mute and Fullscreen buttons.
- **Search ignores accents.** Typing "amelie" finds "Amélie", and accented titles sort where you'd expect.
- **No more false duplicates.** Dropping files while a watched-folder scan was running could report a file as a duplicate of itself.
- **Clearer import errors.** ffmpeg's error output is shortened to one readable line.
- **Posters** are created even if the cache folder was deleted while DropReel was running.
- **Accessibility:** icon buttons, poster cards, dropdowns and the seek and volume sliders now have names that screen readers can announce.
