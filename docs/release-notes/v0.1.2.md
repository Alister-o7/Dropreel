A fix release for DropReel 0.1.1.

## Fixes

- **Smooth fullscreen playback on high-resolution screens.** The player no longer waits inside each UI frame for a video frame's display time. On 4K screens that wait, plus the wait for the monitor's refresh, made frames miss refreshes and stutter.
- **New: Smooth motion** (Settings → Player, on by default). DropReel reads your monitor's refresh rate and has mpv sync the video to it, blending frames so that 24 fps films no longer judder on 60 Hz or 144 Hz screens. Turn it off to get the previous behaviour.
- **Playback diagnostics in the log.** Each playback logs the decoder in use, dropped and late frames, and render times, so a choppy file can be diagnosed from the log alone.
