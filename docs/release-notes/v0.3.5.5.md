Switching to the next episode no longer freezes the window.

## Changes

- **No more freeze when the next episode loads.** Switching episodes (with *Next episode*, **N**, *Play now* or the *Up next* countdown) could freeze the whole window for a moment, or for several seconds on some PCs, and the old episode's last frame stayed on screen. Dropreel no longer waits for the video engine while a new file opens, so the window stays responsive and the new episode's picture appears straight away.
- **Pausing while an episode loads no longer leaves a black screen.** Pressing Space just as an episode was opening could leave "Loading…" on screen until you pressed play again.
- **Pressing Next twice in quick succession** no longer briefly shows the skipped episode's picture or position.
- **Double-clicking the picture** now only switches fullscreen; it no longer pauses and plays as well.
- **No more "duplicate of itself" in the import report** when the same files were added twice at once (for example, dropped while a watched folder was being scanned).
- **Updated video engine** (libmpv), which fixes a rare hang when mpv's own log file is turned on.
- **Better logs for troubleshooting.** The log in `%APPDATA%\Dropreel\logs` now records the video engine's warnings, how long each episode took to load, and any moment the window stops responding.
