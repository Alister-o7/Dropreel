A fix for the next episode sometimes starting frozen.

## Changes

- **The next episode always starts playing.** When the *Up next* countdown ran out (or you chose *Play now*) right at the end of an episode, the next one sometimes stayed stuck on its first frame while the player showed it as playing. It now starts every time.
