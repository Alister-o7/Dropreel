A fix release for DropReel 0.1.0.

## Fixes

- **Smoother playback.** The player no longer waits on mpv while drawing each frame. It redraws in step with your display while a movie plays and reports each frame to mpv, so frames are paced to your monitor's refresh rate.
- **Player controls no longer overlap.** Audio and subtitle menus show a short label (for example `eng · eac3 5.1`) at a fixed width. Long track names, such as release-group titles, only appear in the dropdown, truncated with the full name on hover. Previously they could push the menus over the play button.
- **Simpler sidebar.** The "Over 5 GB" shelf is gone. Movies above the size limit still show a size badge on their poster and keep the **Re-encode to HEVC** option.

## Download

| File | What it is |
|---|---|
| **`DropReel-0.1.1-setup.exe`** | Installer (recommended). It installs over 0.1.0, and your library and settings stay where they are. |
| `DropReel-0.1.1-win64.zip` | Portable version: unzip anywhere and run `DropReel.exe`. |
| `SHA256SUMS.txt` | Checksums for both downloads. |

Requires 64-bit Windows 10 or 11. The files aren't code-signed, so SmartScreen may warn: choose **More info → Run anyway**.

If a movie still doesn't play smoothly, try turning off **Settings → Player → High-quality video scaling**. If that doesn't help, please open an issue and attach an mpv log: start DropReel with `DROPREEL_MPV_LOG=C:\temp\mpv.log` set.
